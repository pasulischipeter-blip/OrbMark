# Orbmark

**Lascia il tuo segno sul mondo 🌍**

Orbmark è una web app personale per tenere traccia dei Paesi, delle regioni e delle zone visitate.

## Versione

**V1.0.0**

## Dati

I dati vengono salvati localmente nel browser/dispositivo.
È disponibile l'esportazione e l'importazione del backup in formato JSON.
